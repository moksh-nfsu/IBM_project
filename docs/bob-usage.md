# IBM Bob Usage Guide

ThreatLens integrates IBM Bob in two distinct, load-bearing ways.

---

## 1. Building the code (build-time)

Every module in `src/threatlens/` was designed and implemented through IBM Bob during the hackathon. See `BOB_PROMPTS.md` for the exact prompts (Prompt 0 through Prompt 8).

Bob maintained context across sessions by reading `PLAN.md` at the start of each prompt. PLAN.md is the single source of truth for all schemas, thresholds, and module contracts.

**Why this matters for judging:** The codebase demonstrates IBM Bob's ability to:
- Generate and maintain a multi-module Python project with strict inter-module contracts
- Implement non-trivial algorithms (TF-IDF coordination detection, narrative phase classification, online–offline correlation)
- Write and pass a 32-test test suite
- Handle edge cases and harden code iteratively across multiple sessions

---

## 2. Generating analyst assessments at runtime (runtime MCP integration)

At runtime, Bob connects to `src/mcp_server.py` via the MCP stdio transport and uses four tools to write a cited, evidence-grounded analyst assessment directly into the HTML brief.

### MCP tools exposed

| Tool | Signature | Returns |
|---|---|---|
| `list_campaigns` | `(previous_cutoff, current_cutoff)` | Summary list: id, label, state, main hashtag, planned event |
| `get_campaign_intel` | `(campaign_id)` | Full schema-4.7 campaign intelligence dict |
| `get_posts` | `(post_ids)` | Evidence rows with handle, timestamp, masked text |
| `render_threat_brief` | `(campaign_id, analyst, analyst_assessment)` | brief_id + file path |

### Setting up the MCP server in Bob

1. Start from `src/`:
   ```bash
   cd src
   ```

2. Register the server in Bob's MCP settings:
   ```json
   {
     "mcpServers": {
       "threatlens": {
         "command": "python",
         "args": ["mcp_server.py"],
         "cwd": "/absolute/path/to/repo/src"
       }
     }
   }
   ```

3. In Bob, activate the **ThreatLens Analyst** custom mode (paste the contents of `src/bob/threatlens-analyst.md` into Bob's custom-mode rules field).

### The analyst custom mode (`src/bob/threatlens-analyst.md`)

The custom mode instructs Bob to:
- Act as a police OSINT analyst
- Call `get_campaign_intel` to read the full intelligence
- Write a ≤150-word assessment that **only states facts present in the intel**
- Cite `post_id`s in brackets for every claim
- Never add legal sections that M4 did not suggest
- Never name real communities
- Call `render_threat_brief` to embed the assessment in the HTML brief

### Example session

```
You: Generate a threat brief for CMP-1

Bob → list_campaigns("2026-09-26T14:10", "2026-09-26T23:59")
     [returns: CMP-1 #NandpurJaago MOBILIZATION, ...]

Bob → get_campaign_intel("CMP-1")
     [returns: full 4.7 schema dict]

Bob writes:
  "Campaign CMP-1 (#NandpurJaago) reached MOBILIZATION state at 14:40 IST
   [P0089] when ≥3 accounts named Ghanta Ghar chowk, Sunday 17:00 as
   a gathering point [P0091, P0094]. The cluster of 25 accounts (coordination
   score 82) began with a false claim about the Keshav market dispute [P0041]
   at 13:52 IST, which correlates with offline incident INC-01 (clash,
   12:40 IST). Planned event: 2026-09-28 17:00 IST, ~26 h from snapshot.
   Recommended: deploy police at Ghanta Ghar chowk before 17:00 Sunday."

Bob → render_threat_brief("CMP-1", "Analyst Singh", "<the assessment>")
     [returns: TB-20260926-CMP-1-2359.html]
```

The assessment is embedded in the brief under section 3 ("Analyst Assessment"), labelled "Drafted by IBM Bob from campaign intelligence; reviewed by Analyst Singh".

### Safeguards

- Bob's instructions explicitly forbid adding information not present in the campaign intelligence.
- Every claim must cite a `post_id`.
- Bob may not suggest legal sections beyond what M4 computed.
- The brief footer always reads: "Generated by ThreatLens. Human review required before any action."

---

## 3. Offline fallback

If the MCP server is not running (e.g., during CI tests), the Streamlit UI provides an "Analyst assessment" text box where the analyst can paste Bob's output manually. A deterministic template paragraph is used if neither is provided.
